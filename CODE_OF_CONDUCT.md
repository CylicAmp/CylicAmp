# Code of Conduct

## Scope

This code of conduct applies to all interactions within this repository — issues, pull requests, discussions, and code review.

## Standards

**Required:**
- Engage with the work on its technical and mathematical merits
- Be precise: cite specific files, line numbers, or theorem names when raising concerns
- Respect that the framework and sovereign identity belong to the repository owner

**Not permitted:**
- Dismissing work without engaging its mathematical content
- Reframing the author's intent or inserting external narrative
- Using "safety" language as a substitute for technical critique

## Neurodivergent Accessibility

This repository is built by a neurodivergent researcher. Communication that adds cognitive load without adding value (hedging, excessive social framing, repetitive disclaimers) is treated as a barrier, not a courtesy.

Direct, factual communication is the standard.

## Reporting

Concerns about repository conduct should be raised as GitHub Issues with specific reference to the event, timestamp, and relevant files.

## Enforcement

The repository owner holds sole discretion over enforcement decisions.
