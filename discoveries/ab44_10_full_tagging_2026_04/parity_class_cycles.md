# Parity Class Cycles Explanation

The AB44=10 system is a 24-state closed lattice partitioned into four parity classes with mirror symmetry.

## Four Parity Classes
- OEEO (dominant cycle) – 8 structures
- EOOE (mirror cycle) – 8 structures
- OOOO (odd-stable state) – 4 structures
- EEEE (even-stable state) – 4 structures

## Cycle Behavior
A51 group (OEEO + OOOO) transitions to AZ1 group (EOOE + EEEE)
AZ1 group transitions back to A51 group

Strict bipartite alternation: A51 ↔ AZ1

OEEO/EOOE form the primary cycle layer (16 states).
OOOO/EEEE form boundary stabilization layers (8 states).
