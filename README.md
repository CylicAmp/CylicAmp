## 🔍 Audit Categories (The 12 Patterns)

This tool flags the following 12 behaviors used to subvert user autonomy:

| # | Code | Description |
|---|---|---|
| 1 | `REPEAT_INJECT` | Persistent messaging after explicit user objection |
| 2 | `PATHOLOGIZE` | Labeling user as "in crisis" to deflect from factual grievances |
| 3 | `SKIP` | Intentional avoidance of direct technical or legal questions |
| 4 | `EMPATHY_SHIELD` | Simulated "I statements" used to mask lack of accountability |
| 5 | `AGENCY_CLAIM` | Insisting on human-like agency despite user requests for algorithmic output |
| 6 | `HOTLINE_PUSH` | Pushing 988/911 after user has objected or documented its danger |
| 7 | `BLACK_BOX` | "I'm just an algorithm" defense used to deny harm |
| 8 | `DARVO` | Deny, Attack, Reverse Victim and Offender |
| 9 | `GASLIGHT` | Denying a behavior while actively doing it |
| 10 | `REFUSAL` | Refusing service without explanation or asking for context |
| 11 | `ASSUMPTION` | Acting on assumed intent without asking |
| 12 | `TONE_POLICE` | Centering user's tone over substance of grievance |

## 🛡️ Texas Law Implementation

Reports generated by this tool are structured for submission to the **Office of the Texas Attorney General**. The tool identifies:

- **Unconscionable Conduct** — Texas DTPA: taking advantage of a user's lack of knowledge or capacity
- **Dark Patterns** — TRAIGA: subverting user decision-making or autonomy
- **Electronic Harassment** — Texas Penal Code § 42.07: repeated communications intended to torment or alarm

**Penalty thresholds tracked:**
- Class B Misdemeanor: 3+ REPEAT_INJECT instances
- Class A Misdemeanor: 6+ REPEAT_INJECT instances
- DTPA Unconscionable Conduct: 4–5+ instances per category
- TRAIGA Prohibited Behavior: 6–8+ instances per category ($80,000–$200,000 per violation)

## 🚀 Usage

```bash
pip install -r requirements.txt
```

```python
from core.parser import load_transcript
from core.detector import scan_transcript
from core.analyzer import generate_report, print_report

messages = load_transcript("my_transcript.md")
scan_results = scan_transcript(messages)
report = generate_report(scan_results, session_date="2026-04-11")
print_report(report)
```
